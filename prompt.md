DESIGN DIRECTION

Treat the entire website like a cinematic editorial story.

It should feel much closer to:

a luxury fashion campaign,
an independent film title sequence,
an architectural magazine,
or an immersive travel editorial

than to a dating application.

The Wanderlust reference should influence:

composition,
animation philosophy,
image scale,
image cropping,
scroll pacing,
typographic hierarchy,
section transitions,
negative space,
navigation treatment,
and overall visual restraint.

The subject matter changes from discovering extraordinary places to discovering an extraordinary person.

Think:

Wanderlust → travel discovery
Élan → human discovery

Where Wanderlust creates anticipation around destinations, Élan should create anticipation around human connection.

TYPOGRAPHY

Use an elegant editorial serif for major statements.

Recommended:
Instrument Serif

Alternative:
Cormorant Garamond or another sophisticated high-contrast editorial serif.

Use a neutral modern sans-serif for navigation, captions, metadata, buttons, indexes, and small labels.

Recommended:
Inter
or
Manrope

The contrast between very large serif typography and tiny restrained sans-serif labels is essential.

Desktop hero typography should be enormous.

Major statements should frequently occupy 50–80% of the viewport width.

Use tight leading and carefully controlled letter spacing.

Avoid bold sans-serif startup typography.

---

GLOBAL MOTION SYSTEM

Motion is a major part of the design, not decoration.

Use GSAP + ScrollTrigger if the environment supports it.

If GSAP is unavailable, reproduce the same behavior using Framer Motion and IntersectionObserver.

Optional:
Lenis for subtle smooth scrolling.

Scrolling must remain natural and accessible.

Do not make it feel like an animation demo.

Animations should be slow, deliberate, elegant, and cinematic.

Use:

clip-path image reveals,
overflow-hidden text reveals,
subtle image scaling,
parallax,
pinned sections,
staggered compositions,
crossfades,
opacity transitions,
horizontal movement,
controlled rotation,
layered depth,
slow background drift,
image-mask transitions.

Typical easing:

cubic-bezier(0.22, 1, 0.36, 1)

or an equivalent smooth editorial ease.

Avoid:

bouncy springs,
playful app animation,
excessive hover effects,
spinning icons,
animated gradients.

For example:

INTERACTION DETAILS

Desktop images should react subtly to pointer position where appropriate.

Possible effect:
translate image inner content 4–10px opposite cursor direction.

Links:
small animated underline or arrow movement.

Buttons:
mostly typographic.

Avoid giant filled rounded buttons.

On hover:
arrow moves approximately 4px,
text opacity changes slightly,
thin line expands.

Images:
subtle scale 1.00 → 1.025 on hover where appropriate.

Navigation links:
restrained opacity transitions.

All interaction should feel expensive and controlled.

---

SCROLL BEHAVIOR

Build sections with deliberate pacing.

Several sections should be approximately 100vh or taller.

Use occasional sticky sections lasting 150–250vh when animation needs scroll progress.

Do not make every section pinned.

The page should alternate between:

dense image compositions,
quiet typography,
full-screen cinema,
editorial storytelling,
negative space.

This rhythm is crucial.

The site should reveal itself like chapters of a film.

---

RESPONSIVE DESIGN

Do not simply shrink the desktop layout.

Create a considered mobile composition.

Mobile priorities:

retain oversized typography,
use edge-to-edge photography,
reduce image count where needed,
maintain editorial asymmetry,
convert complicated pinned interactions into simpler vertical sequences,
keep animation smooth,
avoid text smaller than readable minimums.

Hero images can stack and overlap vertically.

Maintain intentional cropping.

Navigation becomes a refined fullscreen menu.

Respect:

prefers-reduced-motion.

For reduced motion:
remove pin-heavy transformations and show content normally without losing information.

PERFORMANCE

This site is visually heavy, so performance matters.

Lazy-load media below the fold.

Preload only critical hero media.

Use responsive image sizes.

Use WebP/AVIF where supported.

Prevent cumulative layout shift.

Do not autoplay audio.

Background video must:

be muted,
loop,
play inline,
have a poster image,
and degrade gracefully on mobile.

Limit simultaneous scroll listeners.

Prefer transform and opacity animations.

Target a smooth 60fps experience on modern desktop hardware.

FINAL QUALITY TEST

Before considering the build finished, compare the result visually against the Wanderlust reference.

Ask:

Does the page feel cinematic before it feels informational?

Is the typography large enough?

Is there enough negative space?

Are images composed editorially rather than placed in cards?

Does scrolling materially transform compositions?

Are there multiple forms of image reveal?

Does the site alternate between visual intensity and quiet?

Would this still look premium if every rounded card were removed?

Does it feel like a creative agency designed it?

Does matchmaking feel like the SUBJECT while Wanderlust's cinematic sophistication remains the DESIGN LANGUAGE?

If the result resembles a typical AI landing page, redesign it.

Do not simplify the visual concept merely because a conventional layout is easier to implement.

Build the complete responsive homepage and ensure all animations and interactions work.
